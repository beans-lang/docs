## Beans কী?

Beans একটা ছোট object-oriented systems language, তৈরি হয়েছে exact আর low-level —
দুটোই হওয়ার জন্য। accounting আর billing-এর মতো কাজে যেমন সহজ, database আর
operating system-এও তেমন। Source file-এর শেষে থাকে `.b`।

এতে class, interface আর inheritance আছে, সবই reference semantics-এ। grammar
ছোট। হিসাব হয় নিখুঁত `decimal`-এ, তাই কোনো rounding ভুল থাকে না। null নেই,
exception নেই — না-থাকা মান `Option`, ব্যর্থতা `Result`। কোন object কখন মুছে
যাবে তা আগে থেকেই নির্ধারিত, তাই garbage collector হঠাৎ থামিয়ে দেয় না, আর
destructor নির্দিষ্ট সময়ে চলে। raw memory আর C-র সাথে কাজের জন্য একটা `unsafe`
layer আছে। পুরোটা চালায় একটাই compiler, `beansc` — এটি program check করে, হয়
reference interpreter-এ চালায়, নয়তো LLVM দিয়ে native binary তৈরি করে।

```beans
import std.io

fn main() {
    let name: string = "beans"
    io.println("hello from {name}")
}
```

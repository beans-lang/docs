## What is Beans?

Beans is a small programming language for two jobs: **business apps** (accounting,
billing, ERP) and **systems work** (databases, OS and hardware control). Files end
in `.b`.

It gives you Java-style classes and interfaces, a grammar about the size of Go's,
exact `decimal` money math, no null and no exceptions, predictable object
lifetimes with no garbage-collector pauses, and a low-level `unsafe` layer for raw
memory and C interop. One compiler, `beansc`, checks your program and either runs
it on a reference interpreter or compiles it to a native binary through LLVM.

```beans
import std.io

fn main() {
    let name: string = "beans"
    io.println("hello from {name}")
}
```
